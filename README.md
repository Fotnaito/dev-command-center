# Dev Command Center

Personal developer dashboard built with Next.js.

A clean, modern command center that displays GitHub activity, repository stats, and productivity tools in one place.

## Features

- Clean dark-mode dashboard UI
- GitHub profile overview
- Repository & contribution stats
- Recent activity feed
- Extensible widget system

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (icons)
- **Octokit** (GitHub API)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
